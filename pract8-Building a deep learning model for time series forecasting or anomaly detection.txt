Practical No. 8 — Time Series Forecasting using LSTM
# Aim
To develop a deep learning model using LSTM for time series
 forecasting and predict future values from previous observations.

# Requirements
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

# Steps / Procedure
1. Import the required libraries.
2. Generate a time-series dataset using a sine function.
3. Normalize the data using MinMaxScaler.
4. Create input sequences containing the previous 10 values.
5. Use the next value as the target/output.
6. Reshape the input data into the format required by LSTM.
7. Split the data into 80% training and 20% testing data.
8. Create an LSTM model with 50 LSTM units and one Dense output neuron.
9. Compile the model using the Adam optimizer and Mean Squared Error (MSE) loss.
10. Train the model using the training data.
11. Generate predictions using the test data.
12. Convert the normalized predictions back to the original scale.
13. Plot the actual and predicted values for comparison.

#program
# Time Series Forecasting using LSTM

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.preprocessing import MinMaxScaler
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense


# 1. Prepare and normalize data
data = pd.DataFrame(
    np.sin(np.linspace(0, 100, 1000)),
    columns=['value']
)

scaler = MinMaxScaler(
    feature_range=(0, 1)
)

scaled_data = scaler.fit_transform(data)


# 2. Create dataset for LSTM
X, y = [], []

for i in range(len(scaled_data) - 10):
    X.append(
        scaled_data[i:i+10, 0]
    )
    y.append(
        scaled_data[i+10, 0]
    )

X = np.array(X)
y = np.array(y)

# Reshape for LSTM
X = X.reshape(
    X.shape[0],
    X.shape[1],
    1
)


# 3. Split data into train and test
train_size = int(len(X) * 0.8)

X_train = X[:train_size]
X_test = X[train_size:]

y_train = y[:train_size]
y_test = y[train_size:]


# 4. Build the LSTM model
model = Sequential([
    LSTM(
        50,
        input_shape=(X_train.shape[1], 1)
    ),
    Dense(1)
])


# Compile the model
model.compile(
    optimizer='adam',
    loss='mse'
)


# Train the model
model.fit(
    X_train,
    y_train,
    epochs=10,
    batch_size=32,
    verbose=0
)


# 5. Predict
predictions = model.predict(X_test)

# Convert predictions back to original scale
predictions = scaler.inverse_transform(
    predictions
)

y_test = scaler.inverse_transform(
    y_test.reshape(-1, 1)
)


# Plot actual and predicted values
plt.plot(
    y_test,
    label='True'
)

plt.plot(
    predictions,
    label='Predicted'
)

plt.legend()
plt.show()

# Expected Output
A graph will be displayed containing two lines:
- True → Actual time-series values
- Predicted → Values predicted by the LSTM model
The predicted line should generally follow the pattern of the actual sine-wave data.

# Result
The LSTM-based deep learning model was successfully implemented 
for time series forecasting, and the predicted values were compared with the actual values using a graph.

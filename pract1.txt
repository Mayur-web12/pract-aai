Practical: Implement RNN using TensorFlow

# Aim
Implementing advanced deep learning algorithms such as convolutional neural networks (CNNs) or recurrent neural networks (RNNs) using Python libraries like TensorFlow or PyTorch.

# Requirements
- Python
- TensorFlow
- Keras
- IMDb Dataset

# Steps / Procedure
1. Import the required TensorFlow and Keras libraries.
2. Load the IMDb movie review dataset.
3. Select the top 10,000 frequently used words.
4. Pad the reviews to a fixed length of 100 words.
5. Create an RNN model using Embedding, SimpleRNN and Dense layers.
6. Compile the model using Adam optimizer and binary cross-entropy loss.
7. Train the model for 5 epochs.
8. Evaluate the model using the test dataset and display the accuracy.

# Program
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Embedding, SimpleRNN, Dense
from tensorflow.keras.datasets import imdb
from tensorflow.keras.preprocessing.sequence import pad_sequences

max_features = 10000
maxlen = 100

(x_train, y_train), (x_test, y_test) = imdb.load_data(
    num_words=max_features
)

x_train = pad_sequences(x_train, maxlen=maxlen)
x_test = pad_sequences(x_test, maxlen=maxlen)

model = Sequential([
    Embedding(max_features, 32, input_length=maxlen),
    SimpleRNN(32, activation='relu'),
    Dense(1, activation='sigmoid')
])

model.compile(
    optimizer='adam',
    loss='binary_crossentropy',
    metrics=['accuracy']
)

model.fit(
    x_train,
    y_train,
    epochs=5,
    batch_size=64,
    validation_split=0.2
)

test_loss, test_acc = model.evaluate(x_test, y_test)

print(f"Test Accuracy: {test_acc:.2f}")

# Practical No. 10 — Bayesian Optimization

# Aim
To implement Bayesian Optimization for hyperparameter tuning of a Random Forest classifier using the Iris dataset.

# Requirements
- Python
- NumPy
- Scikit-learn
- Scikit-optimize (scikit-optimize)

# Steps / Procedure
1. Import the required Python libraries.
2. Load the Iris dataset.
3. Separate the input features and target labels.
4. Create a Random Forest classifier.
5. Define the hyperparameter search space.
6. Set the number of optimization iterations to 50.
7. Apply Bayesian Optimization using BayesSearchCV.
8. Use 5-fold cross-validation to evaluate different parameter combinations.
9. Train the model and perform hyperparameter optimization.
10. Find the best hyperparameters and the best cross-validation score.
11. Display the optimization results.

#Program


# python -m pip install scikit-optimize

from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

from skopt import BayesSearchCV
from skopt.space import Real, Integer

# Step 1: Load dataset
data = load_iris()
X, y = data.data, data.target

# Step 2: Define the model
model = RandomForestClassifier(random_state=42)

# Step 3: Define the search space
param_space = {
    'n_estimators': Integer(10, 200),
    'max_depth': Integer(1, 20),
    'min_samples_split': Real(0.01, 0.3),
    'min_samples_leaf': Integer(1, 10),
    'max_features': Real(0.1, 1.0)
}

# Step 4: Bayesian Optimization
opt = BayesSearchCV(
    estimator=model,
    search_spaces=param_space,
    n_iter=50,
    cv=5,
    n_jobs=-1,
    random_state=42
)

# Step 5: Perform optimization
opt.fit(X, y)

# Step 6: Display results
print("Best Parameters:", opt.best_params_)

print(
    "Best Cross-Validation Score:",
    opt.best_score_
)

# Expected Output
The output will look similar to:
Best Parameters: {
    'max_depth': 5,
    'max_features': 0.8,
    'min_samples_leaf': 2,
    'min_samples_split': 0.1,
    'n_estimators': 100
}

Best Cross-Validation Score: 0.96

# Result
Bayesian Optimization was successfully implemented to 
tune the hyperparameters of a Random Forest classifier using the 
Iris dataset, and the best parameter combination was obtained.

Practical No. 6 — Reinforcement Learning using Q-Learning

# Aim
Applying reinforcement learning algorithms to solve complex decision-making problems

# Requirements
- Python
- NumPy
- Random module

# Steps / Procedure
1. Import the required NumPy and random libraries.
2. Define a 3 × 3 grid environment.
3. Define the goal state and obstacle state.
4. Define the possible actions: up, down, left and right.
5. Initialize the Q-table with zeros.
6. Set the learning parameters such as learning rate, discount factor and exploration rate.
7. Define the reward function for the goal, obstacle and normal movements.
8. Use the epsilon-greedy strategy to select actions.
9. Perform the selected action and determine the next state.
10. Calculate the reward and update the Q-table using the Q-learning formula.
11. Repeat the process for multiple episodes.
12. Display the learned policy after training.

# #Program

import numpy as np
import random

# Define the environment
grid_size = 3
goal_state = (2, 2)
obstacle_state = (1, 1)

actions = ['up', 'down', 'left', 'right']

action_to_delta = {
    'up': (-1, 0),
    'down': (1, 0),
    'left': (0, -1),
    'right': (0, 1)
}

# Initialize Q-table
q_table = np.zeros(
    (grid_size, grid_size, len(actions))
)

# Parameters
alpha = 0.1
gamma = 0.9
epsilon = 1.0
epsilon_decay = 0.99
min_epsilon = 0.1
episodes = 200


# Reward function
def get_reward(state):
    if state == goal_state:
        return 10
    elif state == obstacle_state:
        return -10
    return -1


# Check if the new state is valid
def is_valid_state(state):
    return (
        0 <= state[0] < grid_size
        and 0 <= state[1] < grid_size
        and state != obstacle_state
    )


# Main Q-learning loop
for episode in range(episodes):

    state = (0, 0)
    total_reward = 0

    while state != goal_state:

        # Choose an action using epsilon-greedy strategy
        if random.uniform(0, 1) < epsilon:
            action = random.choice(actions)
        else:
            action = actions[
                np.argmax(q_table[state[0], state[1]])
            ]

        # Perform the action
        delta = action_to_delta[action]

        next_state = (
            state[0] + delta[0],
            state[1] + delta[1]
        )

        # Stay in the same state if the move is invalid
        if not is_valid_state(next_state):
            next_state = state

        # Get reward
        reward = get_reward(next_state)
        total_reward += reward

        # Find the best next action
        best_next_action = np.max(
            q_table[next_state[0], next_state[1]]
        )

        # Update Q-table
        action_index = actions.index(action)

        q_table[
            state[0],
            state[1],
            action_index
        ] += alpha * (
            reward
            + gamma * best_next_action
            - q_table[
                state[0],
                state[1],
                action_index
            ]
        )

        # Update state
        state = next_state

    # Decay exploration rate
    epsilon = max(
        min_epsilon,
        epsilon * epsilon_decay
    )

    print(
        f"Episode {episode + 1}: "
        f"Total Reward = {total_reward}"
    )


# Display the learned policy
policy = np.full(
    (grid_size, grid_size),
    ' ',
    dtype='<U1'
)

for i in range(grid_size):
    for j in range(grid_size):

        if (i, j) == goal_state:
            policy[i, j] = 'G'

        elif (i, j) == obstacle_state:
            policy[i, j] = 'X'

        else:
            best_action = np.argmax(
                q_table[i, j]
            )

            policy[i, j] = (
                actions[best_action][0].upper()
            )


print("Learned Policy:")
print(policy)

The Q-learning based Reinforcement Learning algorithm 
was successfully implemented, and the agent learned 
a policy to reach the goal while avoiding the obstacle.
